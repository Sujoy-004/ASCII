       - `loadMediaFile(file: File)`: Determines MIME type (`image/*` vs `video/*`), revokes previous object URLs to prevent leaks, creates new local Blob URL, reads natural image/video dimensions, updates `dimensions` and `mediaType` in store, and triggers viewport fit.

|-----------|----------|-----------|----------|-------------|-----------------|
