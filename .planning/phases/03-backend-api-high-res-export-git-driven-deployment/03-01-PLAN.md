<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client Browser -> FastAPI Backend | Untrusted media chunks, job init requests, and parameters crossing public internet |
| Cloudflare CDN -> Render Free Web Service | Proxy edge forwarding client requests with `CF-Connecting-IP` |
| FastAPI Application -> FFmpeg Subprocess | Local OS process boundary executing multimedia commands on disk files |
| Janitor Sweeper -> Local Filesystem | Background disk cleanup operating in `/tmp/ascii_studio_exports/` |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Denial of Service | `src/api/jobs.py` | high | mitigate | Enforce process-local `asyncio.Lock()` admitting strictly 1 export job globally. Concurrent requests fail fast with HTTP 503 and `Retry-After: 30` header per D-02. |
| T-03-02 | Spoofing | `src/api/security.py` | medium | mitigate | Check client socket IP against published `CLOUDFLARE_NETWORKS` CIDRs before trusting `CF-Connecting-IP`. Blind `X-Forwarded-For` is ignored per D-10. |
| T-03-03 | Tampering | `src/api/routes/export.py` | high | mitigate | Require `X-Job-Token` on chunk uploads, cancellation, and status checks. Verify in constant time using `secrets.compare_digest` against SHA-256 hash per D-10. |
| T-03-04 | Information Disclosure | `src/api/routes/export.py` | medium | mitigate | Never expose master `X-Job-Token` in download links. Issue separate short-lived (5 min) single-use download token via query param per D-10. |
| T-03-05 | Denial of Service | `src/api/janitor.py` | high | mitigate | Background janitor checks OS process table (`psutil.pid_exists`) and in-memory job state to protect active jobs while strictly maintaining a 500 MB disk ceiling per D-08. |
| T-03-SC | Tampering | pip dependencies | high | mitigate | All packages (`fastapi`, `uvicorn`, `slowapi`, `httpx`, `python-multipart`, `psutil`) audited [OK] in research Package Legitimacy Audit; verified against PyPI registry. |
</threat_model>
