## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | src/video.py, src/audio.py | high | mitigate | Subprocess invocations strictly use shell=False with explicit argument lists; never pass unvalidated shell commands |
| T-01-02 | Denial of Service | src/renderer.py (resize_rgb24_area, render_frame) | medium | mitigate | Assert buffer length checks len(frame) == expected to reject truncated or corrupted buffers before planar slicing |
| T-01-03 | Denial of Service | src/video.py, src/audio.py | medium | mitigate | Enforce timeout and try/finally terminate and kill backstops on all long-lived subprocesses and worker threads |
| T-01-SC | Tampering | npm/pip/cargo installs | high | mitigate | Zero external runtime dependencies in pyproject.toml; verify only trusted standard dev dependencies (pytest, mypy, ruff) |
</threat_model>

## Artifacts this phase produces

This plan produces and exports the following symbols via `src/__init__.py`:
- `RGBAsciiRenderer`: Core renderer mapping RGB24 frames to ASCII characters and ANSI True Color
- `luminance`: Rec. 601 perceptual luminance function (`0.299*R + 0.587*G + 0.114*B`)
- `char_table_for`: Precomputed 256-entry brightness-to-character lookup table
- `char_for_brightness`: Direct brightness-to-glyph mapper
- `ansi_truecolor`: 24-bit True Color ANSI escape formatter
- `pixel_index`: Byte offset calculator for RGB24 packed frames
- `frame_size`: Byte size calculation for WxH RGB24 frame
- `resize_rgb24`: Point-sampled rescaler
- `resize_rgb24_area`: Pure-Python zero-dependency planar box-averaging frame rescaler
- `Config`: Modernized configuration dataclass (without terminal `status_rows`)
- `DEFAULT_CHARS`: Standard 10-character luminance ramp
- `CHAR_PRESETS`: Dictionary of named character gradients (`default`, `dense`, `simple`, `blocks`)
- `FFmpegFrameReader`: Streaming RGB24 video demuxer and decoder subprocess wrapper
- `ScaleDim`: Scaled video dimensions dataclass
- `classify_decode_termination`: FFmpeg stderr analyzer classifying clean EOF vs fatal container corruptions
- `FFmpegNotFoundError`: Raised when FFmpeg executable is missing from PATH
- `FFmpegDecodeError`: Raised on non-recoverable video stream decode failure
- `AudioPlayer`: Subprocess audio player wrapper for FFplay
- `detect_audio_status`: FFprobe probe for audio track presence
- `has_audio_stream`: Boolean audio stream detector
- `FFplayNotFoundError`: Raised when FFplay executable is missing from PATH
- `FFplayPlaybackError`: Raised on fatal audio playback failure
- `PlaybackTimeline`: Shared observation timeline tracking audio/video drift and playback events
- `AudioStatus`: Tri-state enum (`CONFIRMED`, `ABSENT`, `UNKNOWN`) for audio detection
- `TimestampStream`: Streaming background PTS probe for variable-frame-rate media
- `audio_completion_timeout`: Pacing calculation for natural audio playback completion
- `probe_media_duration`: Probes media container duration via FFprobe
- `probe_video_rate`: Probes container video FPS and CFR status via FFprobe
- `probe_video_size`: Probes video source pixel dimensions via FFprobe
- `FrameClock`: Absolute deadline pacing clock with monotonic and audio clock rebasing
- `TimestampSource`: Protocol for pacing clock providers
- `FrameSelector`: Drained non-blocking frame selector discarding stale frames
- `DropStats`: Frame rendering and drop statistics dataclass
- `TemporalSmoother`: Exponential alpha-blend smoother in RGB24 pixel space
- `QualityController`: Multi-stage dynamic load shedding controller
- `apply_level`: Applies quality degradation level to active levers
